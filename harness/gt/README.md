# Ground-truth provenance and M-R regeneration

## Checked regeneration

Run the complete six-column audit from the 100 explicit released task definitions:

```sh
python harness/gt/audit_targets.py --help
python harness/gt/audit_targets.py --out work.nosync/checked_gt --workers 4 --timeout 120
```

This writes per-task JSON, `audit.json`, `audit.csv` and a working target matrix. Unresolved
or nonmonotonic stellar cases retain NaN rows in that matrix. The shipped target is never
modified. Solver convergence is necessary but does not prove branch stability or global
energy minimization. See the audit output before using a row as a scoring reference.

The checked audit found that historical skip-and-continue reconstruction can reproduce
stored numbers while hiding failed field equations. It is not a convergence validation.
The original random task sampler/seed remains unavailable; regeneration from the explicit
released tasks is reproducible, but their original sampling provenance is not recovered.

## Historical M-R reconstruction

`targets_100x6.original.npy` is the pre-recalibration input. The released
`data/gt/targets_100x6.npy` remains read-only. The scripts here write a working
`targets_100x6.recal.npy` beside the provenance files; they update only columns 4–5
(mass and radius), and assert that columns 0–3 remain bit-identical to the original.

Run from the repository root:

```sh
python harness/gt/recalibrate_mr.py
python harness/gt/fix2276.py
python harness/gt/verify_star.py
```

`recalibrate_mr.py` regenerates the normal beta-EOS rows. Samples 22 and 76 require
skip-and-continue treatment at the failed density and are completed by `fix2276.py`.
The generated M-R columns can then be checked against the shipped target:

```sh
python - <<'PY'
import numpy as np
shipped = np.load("data/gt/targets_100x6.npy")
generated = np.load("harness/gt/targets_100x6.recal.npy")
relative = np.abs(generated[:, 4:6] - shipped[:, 4:6]) / np.maximum(np.abs(shipped[:, 4:6]), 1e-12)
print("maximum relative M/R difference:", relative.max())
assert relative.max() <= 1e-6
PY
```

The four matter-target columns in this historical workflow are preserved from the original
file. `recal_report.json` is the archived historical report;
`recalibration_run_report.json` is generated by a new run. Neither the original inputs
nor the shipped ground truth is modified.
